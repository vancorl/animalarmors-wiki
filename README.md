# AnimalArmors Wiki

Русская документация на Docusaurus. Отдельный репозиторий: исходный код плагина не включён.

Локально: `npm ci`, `npm start`. Проверка: `npm run build`.

Публикация: публичный репозиторий `animalarmors-wiki`, ветка `main`, Settings → Pages → Source → GitHub Actions. Адрес автоматически строится из GITHUB_REPOSITORY_OWNER и GITHUB_REPOSITORY. Репозиторий должен быть проектным, а не `username.github.io`.

Редактируйте Markdown в `docs/`; push в main запускает сборку и публикацию.
