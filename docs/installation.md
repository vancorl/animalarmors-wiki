title: Установка
---

## Требования

Сервер Paper на одной из поддерживаемых версий Minecraft: **1.21.6–1.21.11, 26.1–26.1.2, 26.2 или 26.3**. Версию Java выбирайте по требованиям своего сервера Paper.

Броня наутилусов доступна начиная с Minecraft 1.21.11.

## Установка плагина

1. Остановите сервер.
2. Поместите `AnimalArmors.jar` в папку `plugins/`.
3. Запустите сервер. Плагин создаст папку `plugins/AnimalArmors/` с настройками и готовыми предметами.
4. Настройте отправку ресурспака, как описано ниже.
5. Выполните `/aa reload` и зайдите на сервер. Примите предложенный ресурспак.

Выдайте себе предмет для проверки:

```text
/aa give Steve wolf samurai_wolf_v2
```

Замените `Steve` своим ником. Команда доступна операторам и игрокам с правом `animalarmors.admin`.

## Отправка ресурспака

В `plugins/AnimalArmors/config.yml` включите:

```yaml
enable-self-host: true
self-host-ip: "0.0.0.0"
self-host-port: 8163
```

Плагин сам создаёт ZIP ресурспака и предлагает его игрокам при входе. Для скачивания нужен отдельный **TCP-порт** — в примере это `8163`.

- **На игровом хостинге:** запросите дополнительный порт в панели и укажите его в `self-host-port`.
- **На своём сервере:** разрешите входящие подключения к этому порту в брандмауэре. Если сервер за роутером, настройте проброс порта.

`0.0.0.0` означает, что плагин принимает подключения ко всем сетевым адресам сервера. Если игрокам предлагается ссылка с недоступным адресом, укажите в `self-host-ip` адрес сервера, доступный игрокам.

После изменения настроек выполните `/aa reload`. Если пак не скачивается, откройте предложенную игроку ссылку в браузере с другого устройства.

## Обновление плагина

1. Остановите сервер и сделайте копию папки `plugins/AnimalArmors/`.
2. Замените JAR новым файлом.
3. Запустите сервер.

После замены JAR нужен перезапуск. Для изменений YAML достаточно `/aa reload`.
