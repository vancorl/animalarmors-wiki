title: Установка
---

## Сервер

Используйте Paper совместимой версии. Профили плагина: Minecraft 1.21.6–1.21.11, 26.1, 26.1.1, 26.1.2, 26.2, 26.3. Наутилусы доступны с 1.21.11. Java должна соответствовать требованиям выбранной версии Paper.

1. Остановите сервер и сохраните резервную копию.
2. Поместите полученный `AnimalArmors.jar` в папку `plugins/`.
3. Запустите сервер обычным способом. Текущий режим CUSTOM работает без `-javaagent`.
4. Настройте `plugins/AnimalArmors/config.yml`.
5. Выполните `/aa reload`, войдите на сервер и примите ресурспак.

## Ресурспак для игроков

```yaml
enable-self-host: true
self-host-ip: "0.0.0.0"
self-host-port: 8163
```

`0.0.0.0` слушает все интерфейсы. Для удалённых игроков нужен доступный извне адрес и открытый TCP-порт 8163. На игровом хостинге используйте выделенный дополнительный порт. Проверьте доступность URL пака с устройства игрока.

При `enable-self-host: false` автоматическая раздача выключена: разместите сгенерированный ZIP собственным способом.

## Обновление

Перед заменой JAR остановите сервер и сохраните копию папки плагина. После замены нужен полный запуск. `/aa reload` применяется к конфигам, языкам и предметам, но не заменяет перезапуск после обновления JAR.

Пользовательские каталоги и модели автоматически не сокращаются до стартового набора.
