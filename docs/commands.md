---
title: Команды и права
---

Все команды начинаются с `/aa`. Вместо него можно писать `/animalarmors`.

## Список предметов

```text
/aa list
```

Показывает предметы, доступные на сервере.

## Выдача брони

```text
/aa give <игрок> <животное> <ID> [количество]
```

Например, выдать Steve две алмазные брони волка:

```text
/aa give Steve wolf wolf_diamond_flat 2
```

Если количество не указано, выдаётся один предмет. Угловые скобки из образца вводить не нужно.

| Животное | Значение в команде |
| --- | --- |
| Волк | `wolf` |
| Лошадь | `horse` |
| Лама | `llama` |
| Торговая лама | `trader_llama` |
| Наутилус | `nautilus` |
| Зомби-наутилус | `zombie_nautilus` |

ID готовой брони — в [списке предметов](catalog.md).

## Применение настроек

```text
/aa reload
```

Перечитывает настройки, сообщения, предметы и рецепты. Также создаёт обновлённый ресурспак и предлагает его игрокам на сервере.

Выполняйте после правок YAML или моделей. После замены JAR перезапустите сервер.

## Демонстрационная сцена

`/aa scene all` создаёт сцену для просмотра брони, `/aa scene animate` включает анимацию, `/aa scene clear` убирает сцену.

## Права

Для команд нужно **`animalarmors.admin`**. По умолчанию оно есть у операторов сервера. Обычным игрокам для использования полученной брони это право не требуется.
