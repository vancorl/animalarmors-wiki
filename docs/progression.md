## Алмазная броня волка

Шесть алмазов на верстаке 3×3. `Д` — один алмаз, `.` — пустой слот. Положение фиксировано.

```text
Д . .
Д Д Д
Д . Д
```

Результат: `wolf_diamond_flat`.

## Незеритовое улучшение

В кузнице: шаблон `NETHERITE_UPGRADE_SMITHING_TEMPLATE`, затем `wolf_diamond_flat`, затем один `NETHERITE_INGOT`. Результат — `wolf_netherite_flat`. Самурайская броня основой не служит.

Улучшение сохраняет пользовательское имя, зачарования, экземпляр и износ. Максимальная прочность и характеристики берутся из результата.

## Свой рецепт

Добавьте внутрь определения предмета:

```yaml
crafting:
  enabled: true
  rows:
    - 'DIAMOND;-;-'
    - 'DIAMOND;DIAMOND;DIAMOND'
    - 'DIAMOND;-;DIAMOND'
  book:
    enabled: true
    discover: true
    group: animalarmors
    category: EQUIPMENT
```

Ровно три строки по три слота через `;`. `-` означает пусто. `APPLE:5` задаёт пять предметов в одном слоте. Схему нельзя сдвигать или зеркалить. Сетка 2×2 и блок Crafter не поддерживаются этой механикой.

Блок кузницы задаётся у **результата**:

```yaml
smithing:
  enabled: true
  base: wolf_diamond_flat
  template: NETHERITE_UPGRADE_SMITHING_TEMPLATE
  addition: NETHERITE_INGOT
```

## Починка на наковальне

Необязательный блок внутри предмета:

```yaml
repair:
  enabled: true
  materials: "IRON_INGOT, DIAMOND"
  cost:
    mode: "FIXED"
    levels: 5
```

Один материал восстанавливает 25% максимальной прочности. `FIXED` — общая цена в уровнях; используйте 0–39 для выживания. `VANILLA` учитывает предыдущие операции. Без блока починка на наковальне выключена.

Починка надетой брони волка чешуйкой требует сидящего волка. Починка через Mending от опыта работает в руках игрока; автоматическая починка надетого животного через Mending не добавлена.
