---
title: Настройки плагина
---

Основной файл настроек — `plugins/AnimalArmors/config.yml`. После изменений сохраните файл и выполните `/aa reload`.

```yaml
language: "ru_RU"
allow-enchantments: true
enable-self-host: true
self-host-ip: "0.0.0.0"
self-host-port: 8163
build-folder-location: "AnimalArmors/build"
pack-type: "zip"
emf-etf: true
```

## Что меняет каждая настройка

| Настройка | Для чего нужна |
| --- | --- |
| `language` | Язык сообщений плагина: `ru_RU` или `en_EN`. Не меняет язык этой вики. |
| `allow-enchantments` | Разрешает добавлять «Прочность» и «Починку» с помощью книг на наковальне. |
| `enable-self-host` | Включает отправку ресурспака игрокам через сам плагин. |
| `self-host-ip` | Адрес сервера для раздачи ресурспака. |
| `self-host-port` | TCP-порт для скачивания ресурспака. |
| `build-folder-location` | Куда сохранять созданный ресурспак. Путь считается от папки `plugins/`. |
| `pack-type` | `zip` — сохранить архив, `folder` — сохранить файлы в папке. |
| `emf-etf` | Добавляет в ресурспак поддержку моделей для EMF + ETF и OptiFine. |

При `pack-type: zip` путь из примера создаёт `plugins/AnimalArmors/build.zip`. При `folder` файлы появятся в `plugins/AnimalArmors/build/`.

С настройкой `enable-self-host: true` игроки скачивают ZIP в обоих случаях. Если она выключена, ресурспак нужно разместить и раздавать самостоятельно. Настройка порта описана в [установке](installation.md#отправка-ресурспака).

## Сообщения и цвета

Русские сообщения находятся в `lang/ru_RU.yml`, английские — в `lang/en_EN.yml` внутри папки плагина. Например:

```yaml
prefix: '<gray>[<green>AnimalArmors<gray>]'
reload-ok: '{prefix} <green>Настройки применены.'
```

`<green>` задаёт зелёный цвет, `<gray>` — серый. `{prefix}` подставляет значение из строки `prefix`. Чтобы убрать подпись перед сообщениями, укажите `prefix: ''`.

## Зачарования

При `allow-enchantments: true` броню можно зачаровать на наковальне книгами **«Прочность» I–III** и **«Починка» I**. Стол зачарований не используется.

Значение `false` запрещает добавлять и повышать зачарования. Уже наложенные продолжают работать. Подробности — в разделе [починки и зачарований](progression.md#зачарования).

## Где лежат предметы

```text
plugins/AnimalArmors/
  config.yml       — общие настройки
  lang/            — сообщения
  items/           — настройки отдельных предметов
  models/          — 3D-модели .bbmodel
  textures/        — иконки предметов
```

Добавление брони с примером файла — в разделе [«Свои предметы и модели»](authoring.md).
