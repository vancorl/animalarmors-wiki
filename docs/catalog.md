---
title: Стартовая броня
---

На чистой установке — шесть предметов. Старые установки сохраняют свой каталог.

| ID | Животное | Предмет |
| --- | --- | --- |
| `horse_netherite_flat` | `horse` | Незеритовая плоская броня |
| `wolf_netherite_flat` | `wolf` | Незеритовая плоская броня |
| `wolf_diamond_flat` | `wolf` | Алмазная броня, основа для улучшения |
| `samurai_wolf_v2` | `wolf` | Самурайская броня |
| `llama_sakura` | `llama` | Попона «Сакура» |
| `nautilus_samurai_crimson` | `nautilus` | Самурайская броня Crimson |

## Выдача

```text
/aa list
/aa give Steve wolf samurai_wolf_v2
/aa give Steve llama llama_sakura
/aa give Steve nautilus nautilus_samurai_crimson
```

Замените `Steve` именем игрока. Требуется право `animalarmors.admin`.

Попона семейства LLAMA подходит обычной и торговой ламе. Броня NAUTILUS подходит также зомби-наутилусу. На старых версиях сервера наутилусы скрыты из выдачи.

Алмазная броня волка создаётся на верстаке и улучшается в кузнице — [рецепты](progression.md).
